1. What are the three main layers of software architecture? Write one line about each.
Answer:- 
Layer	                                            Description
Presentation Layer (UI Layer)	            Displays information to the user and accepts user input.
Business Logic Layer (Application Layer)	Processes data, applies business rules, and handles application logic.
Data Layer (Database Layer)	                Stores, retrieves, and manages data in the database.


2. Define client and server in your own words with one real-life example.
Answer:- 
Client:- A client is a device or application that sends a request to access a service or data.
Server:- A server is a computer or system that receives requests from clients and provides the requested data or service.

Real-life Example:
When you open YouTube in your browser, your browser (client) sends a request to YouTube's server, and the server sends back the video and webpage.
